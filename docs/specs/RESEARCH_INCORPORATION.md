## Cross-spec conflicts resolved at the document level

- Default Scoring is now the residual response-total profile used by Sampling and the offline reference, not the earlier Bayesian theta default.
- Reviewed `lemma_pos` is the shared API counting unit; arbitrary dictionary rows do not satisfy that gate.
- Explicit dont_know is accepted; missing/technical responses are not wrong answers; no-score results require null estimate/interval.
- Baseline latent fields are null and public vocabulary claims false across Measurement, Scoring and the machine schema.
- Timeouts/expiry are not psychometric early stopping; stage quotas stay frozen.
- Research slots/consent, single-key review, private lineage and safe result authorization are consistent.
- Full owner-confirmed export replaces missing-full-dictionary assumptions; the failed verifier, deferred migration and empirical gaps remain explicit.

The pre-harmonization specs/roadmap are [archived byte-for-byte](../../raw/specs-before-harmonization/README.md), so detailed earlier alternatives and rationale are not lost. Only the active suite is normative. Original relative links inside the frozen historical documents retain their original context and are not current navigation contracts.

## Verification limits

Machine-schema validation, local links, coverage of all seven specs, source hashes and existing offline tests can be verified now. No API deployment, new standardized owner-data build, human pilot, calibration, production comparison or reopened background research is claimed. Clinical/educational study coefficients, sample sizes and vendor margins remain source-specific research, not production defaults.
